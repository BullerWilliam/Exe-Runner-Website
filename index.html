EXE Runner

Start Windows-programmet app.exe fra samme mappe som denne side. Programmet kører i browserens BoxedWine-emulator.

Kun 32-bit x86-programmer understøttes af denne BoxedWine-udgave.

Klar til at kontrollere app.exe.

Første start henter Wine-miljøet på ca. 37 MB. Kør siden via en webserver, f.eks. python3 -m http.server 8000, og åbn http://localhost:8000/.
